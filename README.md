# Сервис «Умный дом» — ЖК «Панорама парк»

Сайт для приёма заявок и предложений от жителей домов 41, 41А, 41В.

- **Жителям** — виды услуг, заявка на ремонт и обслуживание, проверка статуса, чек-лист работ, предложения и идеи.
- **Администратор** — назначение исполнителей и сроков, передача задачи исполнителю (SMS / WhatsApp / Telegram), чек-лист выполнения, мониторинг, ответы на предложения.

Сайт — один файл `index.html`, без сервера. Данные хранятся в браузере (localStorage), поэтому это демонстрационная версия.
